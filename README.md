# Hazmirryzan Bin Hamsi — TMT3693 Portfolio

A redesigned responsive personal portfolio built with **HTML, CSS, and vanilla JavaScript only**.

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — dark futuristic design and responsive layouts
- `script.js` — interactive features and form validation
- `hazmirryzan-profile.jpeg` — profile photo already included and connected to the homepage

## Run locally
Keep all four files in the same folder and open `index.html` in a modern browser. The portrait is linked automatically; you do not need to select it manually.
